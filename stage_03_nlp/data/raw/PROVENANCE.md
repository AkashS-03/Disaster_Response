# Stage 03 NLP - Data Provenance

All files below are REAL disaster-related text data. Each row of text in the training corpora is either a real
humanitarian message (Figure Eight) or a real tweet (Kaggle) that was hand-labelled.

| File | Size | Description | Source URL |
| :--- | ---: | :--- | :--- |
| disaster_messages.csv | 5,064,273 | Figure Eight CrowdFlower Disaster Response Messages (via public mirror) | https://raw.githubusercontent.com/ravishchawla/ETL-Pipeline-for-Disaster-Data/master/data/disaster_messages.csv |
| disaster_categories.csv | 11,854,295 | Figure Eight CrowdFlower Disaster Response Categories / labels (via public mirror) | https://raw.githubusercontent.com/ravishchawla/ETL-Pipeline-for-Disaster-Data/master/data/disaster_categories.csv |
| disaster_tweets_train.csv | 987,712 | Kaggle - NL with Disaster Tweets - training set (real tweets, binary target) | https://raw.githubusercontent.com/Satwato/Kaggle-NLP-with-Disaster-Tweets/master/train.csv |
